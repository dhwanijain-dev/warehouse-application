# Installation via Download Link (Sideloading)

Warehouse Scan is designed for enterprise deployment on Zebra handheld scanners without depending on the Google Play Store.

1. **Hosting the APK**: Host the signed release APK on your internal server or secure file share.
2. **Device Setup**: On the Zebra handheld, open the download link in the browser.
3. **Permissions**: When prompted, enable **Install unknown apps** for the browser or file manager.
4. **Installation**: Tap the downloaded APK and select **Install**.
